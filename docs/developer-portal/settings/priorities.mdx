**Settings → Priorities** decides which data source is shown when more than one source has data for the same period. This matters as soon as a user connects several providers or wears several devices from the same provider.

## Provider Priorities

Use the arrows to reorder the list, then click **Save Changes**. Higher in the list means higher priority.

The list contains every supported provider from the start, seeded with a default order when the API boots. Providers added in a later release are appended below the ones you have already ordered, so an upgrade never reshuffles your configuration.

How it works:

- When data from multiple providers overlaps in time, the higher-priority provider's data is shown.
- Within the same provider, watch data is preferred over phone data by default. You can change that below.

## Device Type Priorities

The second list orders device types within a single provider: **Watch**, **Band**, **Ring**, **Phone**, **Scale**, **Other**, and **Unknown**. When the same provider delivers data from two devices, the higher-priority device type wins.

Daily activity summaries are the exception. Each metric of a day comes from the highest-priority provider that stored it on that day, so a ring that synced heart rate but no daily activity record keeps its heart rate while the steps come from the next provider, and a band that reports energy and no steps does not turn the day into zero steps. Active and basal energy are taken together from one provider, and so are the heart-rate statistics, so a day never adds one provider's active energy to another's basal energy. The summary's `source` is the provider that supplied the steps. A day that no provider counted steps for reports `steps: null`, not zero.

Within the provider that supplies an additive metric (steps, active and basal energy, walking and running distance, flights climbed), the total also counts hours the winning device missed:

- Each hour of the user's local day takes the larger sum from that provider's devices, so a walk recorded by both a watch and a phone is counted once.
- The hourly values are added up for the day. Hours where only the phone recorded anything still count, so a watch worn for part of the day no longer hides the phone's steps for the rest of it.
- A larger daily total reported by the provider itself is kept.
- Samples from different providers are never added together.

Active minutes and intensity minutes follow the device whose steps or heart rate they are derived from.

Reorder with the arrows and click **Save Changes**. The two lists are saved independently.
